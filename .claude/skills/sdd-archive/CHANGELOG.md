# Changelog — sdd-archive

- **v0.1** — first version. Skill that closes the Spec Kit SDD cycle by archiving features whose development and verification have finished. Inspects `verify-report.md` (generated by `sdd-verify`); if it detects at least one criterion in `fail` or `no verificable`, it refuses the archive and explicitly lists the blocking criteria (FR-005). If all criteria are in `pass`, it obligatorily applies an explicit human confirmation gate (Principle III of the constitution) before modifying any file. After confirmation, it generates `state.yaml` with the 4 exact Data Model fields (`feature`, `estado`, `fecha_archivado`, `resumen_verify`) and moves the feature's complete folder to `specs/_archive/` (creating it if it does not exist, FR-006). Handles the edge case of re-running on already archived features or features with a prior `state.yaml` idempotently, reporting their state without repeating the action.
